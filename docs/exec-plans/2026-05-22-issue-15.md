## 주의

- Kakao 응답의 x(경도), y(위도) 순서 주의 → lat=Number(y), lng=Number(x)
- `EXPO_PUBLIC_KAKAO_REST_API_KEY` 를 `.env`에 추가해야 함 (네이티브 앱 키와 다른 키)
- Kakao dapi.kakao.com은 별도 axios 인스턴스 사용 (백엔드 api 인스턴스와 분리)
