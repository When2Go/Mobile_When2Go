## 목표

`@react-native-firebase` v24 환경에서 deprecated namespaced API(`messaging().*`)를
modular API(`getMessaging`/`requestPermission`/`getToken`)로 치환한다.
기능 변화 없음. Metro 콘솔의 deprecation WARN 4건 제거가 목적.

## 관련 파일

- `src/hooks/common/useFcmToken.ts` — RNFB messaging 유일 사용처
- `src/hooks/common/__tests__/useFcmToken.test.ts` — jest mock을 modular 구조로 갱신

## 작업 분해

- [ ] `useFcmToken.ts`: import를 modular로 변경
  - `import { getApp } from '@react-native-firebase/app'`
  - `import { getMessaging, requestPermission, getToken, AuthorizationStatus } from '@react-native-firebase/messaging'`
  - `messaging().requestPermission()` → `requestPermission(getMessaging(getApp()))`
  - `messaging().getToken()` → `getToken(getMessaging(getApp()))`
- [ ] 테스트 mock 갱신: `@react-native-firebase/app`의 `getApp`, messaging의 `getMessaging`/`requestPermission`/`getToken`을 각각 named export mock으로
- [ ] 기존 14개 테스트 동일하게 통과
- [ ] ESLint + TypeScript 통과

## 완료 기준

- 기능 동작 변화 없음 (토큰 발급 + 등록/갱신/skip 흐름 동일)
- RNFB deprecation WARN 4건 제거
- 기존 14개 단위 테스트 그대로 통과
- ESLint + TypeScript 에러 없음
- iOS · Android 양쪽 직접 테스트 (사용자 실기기 확인)
