## 설계 메모

- **API endpoint**: `POST /api/trips/parse` (확정, 2026-06-20)
- **응답 구조**: `{ endLocation: string; appointmentTime: string }` (ISO 8601 로컬)
- **VoiceModal.onComplete 시그니처 변경**: `() => void` → `(result: VoiceRecognitionResponse) => void`
- **setup.tsx 파라미터**: `destination` (기존) + `appointmentTime` (신규 ISO 문자열)
- **파싱 로직**: `parseAppointmentTime("2026-06-25T18:30:00")` → `{ date: Date(2026-06-25), period: '오후', hour: 6, minute: 30 }`
