# issue #106 — iOS 실제 잠금화면 Live Activity / Dynamic Island 네이티브 구현

- 원본 이슈: https://github.com/When2Go/Mobile_When2Go/issues/106
- Labels: `feature`, `widget`
- PRD ID: F-W01, F-W03, F-W04, F-W05 (+ F-W06 위젯 끄기)

## 확정된 방향 (사용자 확인)

- **구현 방식**: `expo-apple-targets` 로 iOS Widget Extension 타겟을 prebuild(CNG)에 주입.
  - `ios/` 는 gitignore 대상 → 네이티브 타겟은 config plugin 으로만 관리.
- **라이프사이클**: 백엔드 APNs "출발 10분 전" 푸시 → Live Activity **시작**,
  사용자가 첫 대중교통을 **탑승해야 하는 시점**(boarding time) → Live Activity **종료**.
  - 시작은 APNs push-to-start(iOS 17.2+) 또는 포그라운드 수신 시 로컬 시작(폴백).
  - 종료는 boardingDate 도달 시 로컬 종료 + 백엔드 최종 push 둘 다 대비.

## 범위 경계

- **In scope (프론트)**: 위젯 타겟·ActivityAttributes·SwiftUI 뷰·App Group·RN 네이티브 모듈
  (start/update/end + push token)·JS 훅/유틸·토큰 등록 API 스텁·빌드 문서.
- **Out of scope (백엔드 레포)**: 실제 APNs 서버 전송 인프라, Live Activity 토큰 저장 엔드포인트 구현.
  - 프론트는 토큰을 받아 백엔드로 보내는 클라이언트 측까지만. 엔드포인트는 협의 후 연결.
