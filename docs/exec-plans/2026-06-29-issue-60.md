## 목표

Kakao Local API REST 키(`EXPO_PUBLIC_KAKAO_REST_API_KEY`)가 앱 JS 번들에 인라인 노출된 상태에서,
회의 결정(프론트 직접 호출)을 유지하면서 abuse 비용을 올리고 blast radius를 좁히는 단기 조치를 완료한다.

---

| 파일 | 작업 |
|------|------|

| `.env.example` | 발급 절차 주석 보완 |
| `docs/DEPLOY.md` | 키 회전 절차 섹션 신규 추가 |

- [ ] **`docs/DEPLOY.md` 키 회전 절차 섹션 추가** — 다음 내용 포함:
