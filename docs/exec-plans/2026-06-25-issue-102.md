## 목표

`react-native-google-mobile-ads` + Expo config plugin을 설정하고, `AdSlot`이
`EXPO_PUBLIC_ADS_ENABLED` 값으로 placeholder ↔ 실 SDK(BannerAd)를 분기하는 구조를 마련.
기본값 `false`라 심사 전까지는 기존 회색 placeholder가 그대로 노출.
실 광고 노출 활성화(=true)는 **심사 통과 후 별도 PR**로 분리.

## 정책 가드

- CLAUDE.md §10 / docs/FRONTEND.md §7 — 심사 전 placeholder 유지가 기본.
- 이 PR은 ADS_ENABLED=false 기본. 실 단위 ID는 .env(gitignore)에만, 코드/예시엔 테스트 ID.
- 키 발급 완료: App ID 2종 + 배너 단위 4종(iOS/Android × content/splash). .env 주입.

## 발급된 키 (실값은 .env 에만)

- env 키 이름만 코드/example에 노출. 실 값은 사용자 .env 로 관리.

## 관련 파일

- `app.config.ts` — plugins에 react-native-google-mobile-ads 추가(androidAppId/iosAppId/ATT 문구)
- `.env.example` — ADS 관련 env 양식 추가 (기본 ADS_ENABLED=false)
- `src/config/ads.ts` (신규) — ADS_ENABLED 플래그 + getBannerUnitId(type) 분기(실↔테스트)
- `src/config/__tests__/ads.test.ts` (신규, TDD) — 분기·fallback 단위 테스트
- `src/components/common/AdSlot.tsx` — ENABLED면 BannerAd, 아니면 기존 placeholder
- `app/_layout.tsx` — ENABLED일 때만 ATT 요청 후 mobileAds().initialize()
