## 2. 사용자 직접 진행 (NCP 셋업)

코드 작업 전에 다음 단계가 필요하다. 작업을 끝낸 뒤 `.env`에 키만 넣어주면 된다.

1. **NCP 콘솔 가입/로그인** — https://console.ncloud.com
2. **Maps 상품 신청** — `Services` → `AI·NAVER API` → `Maps` (개편된 신 단독 상품; 결제 수단 등록 필요하지만 Mobile Dynamic Map은 무제한 무료라 청구되지 않음)
3. **Application 등록**
   - 서비스 환경: iOS + Android 둘 다 추가
   - iOS Bundle ID: `kr.co.when2go.app`
   - Android Package Name: `kr.co.when2go.app`
4. **NCP Key ID 발급** — 등록한 Application의 상세에서 `Client ID` (신 Maps 상품은 `NCP Key ID`라 부르기도 함)를 복사
5. **로컬 `.env`에 추가**
   ```
   EXPO_PUBLIC_NAVER_MAP_NCP_KEY_ID=발급받은_NCP_KEY_ID
   ```
   `.env`는 gitignore. 절대 커밋 금지.
6. **EAS 환경에도 등록** — `eas secret:create --scope project --name EXPO_PUBLIC_NAVER_MAP_NCP_KEY_ID --value <key>` (development/preview/production 환경 별로 또는 공통으로)

검증: 사용 단위가 Mobile Dynamic Map SDK 호출만이라면 청구서가 발생하지 않는다. NCP 콘솔의 사용량 대시보드로 모니터링.

## 3. 코드 변경 사항

### 3.1 의존성 (package.json)

추가:
```json
{
  "dependencies": {
    "@mj-studio/react-native-naver-map": "^2.8.0",
    "expo-location": "~19.0.8",
    "expo-build-properties": "~1.0.10"
  }
}
```

설치 명령: `npx expo install @mj-studio/react-native-naver-map expo-location expo-build-properties`

> `expo-build-properties`는 Naver Maps Android SDK의 Maven 저장소(`https://repository.map.naver.com/archive/maven`)를 root project에 주입하기 위해 필요. Naver Maps SDK는 mavenCentral에 없고 Naver 자체 Maven에만 호스트된다. 패키지 자체의 build.gradle은 `mavenCentral`/`google`만 선언하므로 root에서 주입해야 `com.naver.maps:map-sdk:3.23.0` 의존성이 resolved됨.

transformIgnorePatterns는 변경 불필요 — naver-map은 lib에 commonjs를 빌드해 출시하므로 Jest는 그대로 처리 가능. 만약 jest에서 fail이 나면 그때만 `@mj-studio/.*`를 추가.

### 3.4 `src/hooks/location/useCurrentLocation.ts` 신규

PR #54의 구현을 참고하되 cherry-pick이 아닌 새로 작성. 동작 사양은 동일:
- `expo-location.requestForegroundPermissionsAsync` 권한 요청
- 허용 시 `watchPositionAsync` 구독 (Balanced 정확도, 10s/10m 갱신)
- 거부 시 서울 시청 기본 좌표(`37.5666791, 126.9782914`) 폴백
- 언마운트 시 구독 해제
- 반환: `{ lat, lng, isGranted, isLoading, error }`

상수는 파일 상단에 선언 (`DEFAULT_LAT`, `DEFAULT_LNG`, `WATCH_TIME_INTERVAL=10000`, `WATCH_DISTANCE_INTERVAL=10`).

### 3.5 `src/hooks/location/__tests__/useCurrentLocation.test.ts` 신규 (TDD)

4축 + 라이프사이클:
- 정상: 권한 허용 → watchPositionAsync 콜백 좌표 반환, `isGranted=true`

### 3.6 `src/components/home/MapPreview.tsx` 재작성

현재 placeholder(그리드 + 중앙 점 + 캡션) → 실제 NaverMapView.

```tsx
import { Text, View } from 'react-native';
import {
  NaverMapView,
  NaverMapMarkerOverlay,
} from '@mj-studio/react-native-naver-map';

import { useTheme } from '@/contexts/ThemeContext';
import { useCurrentLocation } from '@/hooks/location/useCurrentLocation';

const INITIAL_ZOOM = 15;
const FALLBACK_NOTE = '위치 권한이 없어 서울 시청을 기준으로 표시합니다.';

export default function MapPreview() {
  const { isDark } = useTheme();
  const { lat, lng, isGranted, isLoading } = useCurrentLocation();

  const baseBg = isDark ? 'bg-zinc-800' : 'bg-zinc-200';
  const captionText = isDark ? 'text-zinc-400' : 'text-zinc-500';

  if (isLoading) {
    return (
      <View
        className={`flex-1 items-center justify-center ${baseBg}`}
        accessibilityLabel="지도 미리보기 로딩"
      />
    );
  }

  return (
    <View className="flex-1" accessibilityLabel="지도 미리보기">
      <NaverMapView
        style={{ flex: 1 }}
        initialCamera={{ latitude: lat, longitude: lng, zoom: INITIAL_ZOOM }}
        isShowLocationButton={false}
        isShowZoomControls={false}
        isShowCompass={false}
        isShowScaleBar={false}
      >
        <NaverMapMarkerOverlay
          latitude={lat}
          longitude={lng}
          anchor={{ x: 0.5, y: 1 }}
        />
      </NaverMapView>

      {!isGranted && (
        <View className="absolute bottom-2 left-0 right-0 items-center">
          <Text className={`text-[11px] font-medium ${captionText}`}>
            {FALLBACK_NOTE}
          </Text>
        </View>
      )}
    </View>
  );
}
```

CLAUDE.md 준수:
- NativeWind 시맨틱 토큰만 (`bg-zinc-*`, `text-zinc-*`) — 하드코딩 색상 X
- 다크모드 조건부 (`isDark`)
- 숫자 리터럴은 상수 (`INITIAL_ZOOM`)
- 도메인별 훅 (`hooks/location/`)
