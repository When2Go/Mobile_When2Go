## SDK API 파악 결과

`@react-native-kakao/map@2.2.7` 핵심 API:

```ts
// 초기화 — 앱 시작 시 1회
KakaoMap.initializeKakaoMapSDK(appKey: string): Promise<void>

// 지도 컴포넌트 (ViewProps 확장)
<KakaoMapView
  camera={{ lat, lng, zoomLevel }}  // 카메라 위치 (controlled)
  initialCamera={{ lat, lng, zoomLevel }}  // 초기 카메라 (uncontrolled)
  language="ko"
  isShowCompass={boolean}
  baseMapType="map" | "skyview"
/>

// Camera 타입
interface Camera { lat: number; lng: number; tilt?: number; rotation?: number; zoomLevel?: number; }
```

**중요**: KakaoMapView에 내장 마커(marker) prop 없음 → RN View 오버레이로 현재 위치 마커 구현.
