## 목표

반복 예약 단건마다 안전 버퍼 시간을 직접 지정할 수 있게 만든다. 미설정 시 전역 설정값(`useSettingsStore.bufferMinutes`)을 fallback 으로 사용하고, 반복 예약 기반 Trip 의 출발 시간 계산에 그 버퍼가 전달되도록 단일 해석 함수를 둔다.

## 설계 결정

1. **저장 방식**: `RepeatItem.safetyBufferMin?: number` (optional). undefined 이면 "전역 설정 사용", 숫자면 "직접 설정". 이렇게 두면 전역값 변경 시 fallback 케이스는 자동 추종한다.
2. **fallback 해석**: 순수 함수 `resolveRepeatBufferMinutes(repeat, globalBufferMin)` 한 군데서만. Trip 자동 생성 코드는 항상 이 함수를 거치도록 한다.
3. **UI 재사용**: `BufferSheetBody` 의 슬라이더 영역을 `BufferSlider` 로 추출해 모달 안에 인라인 배치. 슬라이더 단독은 저장/취소 버튼이 없는 형태로, 폼 상태에 즉시 반영한다. `BufferSheetBody` 는 `BufferSlider` 를 감싸 기존 동작(저장/취소) 유지.
4. **모달 내 UX**: 도착 시간처럼 collapsible 행. 행 우측에 "전역 설정 사용" / "직접 설정 N분" 배지. 펼치면 슬라이더 + "전역 설정으로 되돌리기" 링크.
