## 목표

모든 도메인 API가 단일 axios 인스턴스를 통하고, 디바이스 ID가 자동 헤더 주입되며, 401/403/네트워크/타임아웃 에러가 일관된 형태로 정규화된다.

## 현황 (이슈 #30에서 선행 완료된 부분)

`feat(api): axios 인스턴스 + X-Device-Id 자동 주입 셋업 (#30)` (commit `94bf67d`)에서 이미 구현됨:

- ✅ `src/api/axios.ts` — `axios.create({ baseURL, timeout })` + `X-Device-Id` **요청** 인터셉터(인라인)
- ✅ `src/stores/deviceStore.ts` — UUID v4 생성 + AsyncStorage 영속화 (`persist`)
- ✅ `src/stores/__tests__/deviceStore.test.ts` — 생성/재사용 단위 테스트
- ✅ `app/_layout.tsx` — `ensureDeviceId()` 부트스트랩 훅

→ #14에서 **새로 만들지 않는다**. 이슈 체크리스트 중 deviceStore / axios 기본 인스턴스 / _layout 항목은 이미 완료로 간주.
