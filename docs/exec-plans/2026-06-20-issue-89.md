# exec-plan: 선택 경로 폴리라인 지도 표시

- **이슈**: https://github.com/When2Go/Mobile_When2Go/issues/89
- **Labels**: feature
- **브랜치**: `feat/issue-polyline-map#89`

## 목표

`POST /api/routes/search` 응답의 `polyline.encodedPolyline`을 디코딩해 홈 화면 네이버 맵 위에 선택 경로를 폴리라인으로 표시한다.

## 구현 결정 사항

- **언제 그릴 것인가**: 경로 선택(RouteCard 탭) 즉시 → `routeDraftStore.selectedPolyline` 갱신 → 홈 MapPreview에서 렌더
- **폴리라인 레벨**: Route 레벨 `polyline.encodedPolyline` 사용 (전체 이동 경로 표현)
- **별도 미리보기 화면**: 미도입 (MVP 범위 초과). 홈 맵에 오버레이로 표시
- **카메라 이동**: MVP에서는 폴리라인만 추가, 카메라 이동 없음
