# Issue #58 — 다크모드 일괄 제거 (추후 재도입 여지 유지)

- 원본: https://github.com/When2Go/Mobile_When2Go/issues/58
- Labels: refactor
- Branch: `refactor/issue-remove-dark-mode#58`

## 목표

화면/컴포넌트마다 반복되는 `isDark ? darkClass : lightClass` 분기를 라이트 값으로 일괄 정리합니다. `ThemeContext` 골격(`ThemeProvider` / `useTheme()` / `tailwind.config.js` `darkMode: 'class'`)은 추후 재도입을 위해 보존합니다.

## 전략

"ThemeContext 골격만 유지" 전략을 채택합니다.

1. `useTheme()` 시그니처 `{ isDark, mode, setMode, toggle }`를 유지합니다.
2. `isDark`를 상수 `false`로 고정하고 `useColorScheme` / `colorScheme.set` / 토글 로직을 제거합니다.
3. 52개 파일에서 `isDark ? darkClass : lightClass`를 라이트 값으로 정리합니다.
4. `useTheme()` 의존성이 사라진 컴포넌트는 import도 제거합니다.
5. 마이페이지의 `DarkModeRow`를 제거합니다.

## 주의사항

- `ThemeContext` / `useTheme` / `ThemeProvider` / `tailwind.config.js` darkMode 설정은 **절대 제거 금지** (재도입 골격)
- 분기에서 라이트 값을 그대로 추출만 합니다. 값을 임의로 바꾸지 않습니다.
- `PALETTE` 상수 자체는 건드리지 않습니다.
- `DarkModeRow` 자리에 빈 줄/border 깨짐이 생기지 않는지 확인합니다.
