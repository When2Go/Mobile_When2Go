## 목표

Android Foreground Service + Ongoing Notification 기반으로 실제 잠금화면/알림 영역에
출발 타이밍 위젯을 띄우는 네이티브 구현.

- FCM high-priority data 메시지 수신 시 자동 시작 (출발 10분 전)
- 15초 로컬 틱으로 남은 분·진행도 갱신
- boardingEpoch 도달 시 자동 종료
- 위젯 끄기(F-W06): 즉시 종료

iOS Live Activity(#106)와 동일한 아키텍처 패턴을 따름.
