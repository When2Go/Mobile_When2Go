## 목표

경로 설정 화면에서 변경한 안전 버퍼 로컬 오버라이드 값을 출발 시간 계산 결과 화면으로 전달하여, 계산·표시에 정확히 반영되도록 수정한다.

## 원인

- `app/setup.tsx:91` `router.push(RESULT_PATH)` 시 `safetyBufferMin` (로컬 오버라이드 결합값)을 라우트 파라미터로 전달하지 않음.
- `app/result.tsx:29` `useSettingsStore((s) => s.bufferMinutes)` 전역 store 값만 읽어 setup 로컬 오버라이드를 수신할 경로가 없음.

## 수정 범위

| 파일 | 변경 내용 |
|------|---------|
| `src/constants/result.ts` | `BUFFER_MIN_PARAM = 'bufferMin'` 라우트 파라미터 키 상수 추가 |
| `app/setup.tsx` | `handleDepart`에서 `{ pathname, params: { [BUFFER_MIN_PARAM]: safetyBufferMin } }` 전달 |
| `app/result.tsx` | `useLocalSearchParams`로 `bufferMin` 읽기, 없으면 전역 store fallback |
