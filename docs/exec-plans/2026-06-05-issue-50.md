## 목표

`setup` 화면에서 "출발 시간 계산하기"를 누르면 Spring Boot 프록시를 경유해 Google Maps 기반 경로 탐색 API를 호출하고, `result` 화면에 실제 경로 데이터를 표시한다.

**백엔드 변경사항**: ODsay → Google Maps 전환으로 API 구조가 크게 바뀌었다.

- GET → **POST** `/api/routes/search`
- 요청: `originLat/Lng`, `destLat/Lng`, `arrivalTime(HH:mm)` — `routeOption` 제거
- 응답: Google Maps 구조 (`legs` → `steps` → `transitDetails`)

## 데이터 흐름

```
setup.tsx
  useCurrentLocation() → 현재 GPS 좌표
  handleDepart() → setCoords('from', GPS) → routeDraftStore
                → router.push({ arrivalTime: toHHmm(...) })
        ↓
result.tsx
  fromCoords ← routeDraftStore
  toCoords   ← routeDraftStore
  arrivalTime ← route params
  → useRouteSearch({ originLat, originLng, destLat, destLng, arrivalTime })
        ↓
  RouteCandidate[] → normalizeRoute() → RouteDisplayItem[]
  → RouteCard[]
```
